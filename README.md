# hi — NFC-визитка

Страница, которая открывается по ссылке с NFC-метки. Сама выбирает оформление по телефону:
на Android — карточка в стиле Material 3, на iPhone — «жидкое стекло».

- `index.html` — вся страница, без зависимостей.
- `c/<id>.json` — данные визитки (заголовок, подпись, имя, телефон, Telegram, картинка).
- `c/<id>.vcf` — контакт для кнопки «сохранить».
- `m/<id>/` — гифка или фото. С прозрачным фоном (`"cutout": true`) персонаж выпрыгивает из карточки.

Визитки публикует приложение «Опись» через GitHub API. Ссылка на метке: `https://arti-ko.github.io/hi/?<id>`.
Для проверки стиля: `?demo&ios` или `?demo&android`.
