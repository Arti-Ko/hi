# hi — NFC-визитка

Страница, которая открывается по ссылке с NFC-метки: крупная типографика и персонаж,
который следит за пальцем и наклоном телефона. Кнопки снизу на iPhone — «жидкое стекло».

- `index.html` — вся страница, без зависимостей.
- `c/<id>.json` — данные визитки: приветствие, имя, кто я, возраст, о себе, телефон, почта, Telegram, Instagram, картинка.
- `c/<id>.vcf` — контакт для кнопки «сохранить».
- `m/<id>/` — своя картинка вместо нарисованного персонажа (наклоняется вслед за пальцем).

Визитки публикует приложение «Опись» через GitHub API. Ссылка на метке: `https://arti-ko.github.io/hi/?<id>`.
Для проверки стиля: `?demo&ios` или `?demo&android`.
