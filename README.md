# hi — NFC-визитка

Карточка для знакомства: открывается по ссылке с NFC-метки. Фото (наклоняется за пальцем
и наклоном телефона), имя и возраст, одна фраза, интересы и кнопки «Написать в Telegram» и Instagram.

- `index.html` — вся страница, без зависимостей.
- `c/<id>.json` — что пишет «Опись»: имя, возраст, кто я, телефон, почта, Telegram, Instagram, фото.
- `c/<id>.extra.json` — правится вручную: фраза (`line`, *курсив* звёздочками), интересы (`likes`),
  подсказки (`prompts`: `[{q, a}]`), плашка статуса (`status`).
- `c/<id>.vcf` — контакт для кнопки «сохранить».
- `m/<id>/` — фото.

Визитки публикует приложение «Опись» через GitHub API. Ссылка на метке: `https://arti-ko.github.io/hi/?<id>`.
Для проверки стиля: `?demo&ios` или `?demo&android`.
